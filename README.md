# SHADOW NEST

เกมยิงมุมมองบุคคลที่หนึ่งสายลับแบบ low-poly — ซุ่มบนหอ แอบในเงา แล้วยิงนัดเดียวจบ

**เล่นเกม:** [nongtum-bit.github.io/shadow-nest](https://nongtum-bit.github.io/shadow-nest/)

**ซอร์ส:** [github.com/nongtum-bit/shadow-nest](https://github.com/nongtum-bit/shadow-nest)


## ด่าน

| รหัส | สถานที่ | จุดซุ่ม |
| --- | --- | --- |
| DOCKYARD | ท่าริมน้ำ / คลังสินค้าท่าเรือกลางคืน | หอเครนด้านตะวันออก |
| VILLA PERCH | คฤหาสน์บนเขา / วิลล่าหินในสวนจันทร์ | ดาดฟ้าวิลล่า / หอสวน |
| SAND BASE | ฐานทราย / ฐานทัพทะเลทรายยามสนธยา | หอวิทยุกลางลาน |

## วิธีเล่น

- **WASD** เดิน · **Shift** วิ่ง · **Ctrl / C** ย่อตัว
- **เมาส์** มองรอบ · **คลิกซ้าย** ยิง · **คลิกขวา** ส่องกล้องสไนเปอร์
- **1 / 2** สลับปืนสั้นเก็บเสียง กับ Kestrel .338
- **R** บรรจุกระสุน · **E** ปิดเงียบจากด้านหลัง / เก็บแฟ้มข่าวกรอง
- กำจัดเป้าหมายสำคัญ เก็บข่าวกรอง แล้วเข้าโซนถอนตัว

แรงค์จบด่าน: **GHOST** (ไม่ถูกพบ) · **SHADOW** · **OPERATIVE**

บนมือถือมีจอยซ้าย เล็งขวา และปุ่มยิง / เล็ง / ย่อ

## รันบนเครื่อง

ต้องการ Node.js 22+

```bash
npm install
npm run dev
```

เปิดเบราว์เซอร์ที่พอร์ตที่สคริปต์ dev แสดง จากนั้นเริ่มปฏิบัติการจากหน้าเมนู

```bash
npm run build
npm run typecheck
```
